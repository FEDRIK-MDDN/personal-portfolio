# 📸 Project Screenshots Guide

## How to add images for each project

Drop your image files inside the matching project folder below,
then follow the import instructions in `src/App.jsx`.

```
src/assets/images/
├── project1/          ← Movie & TV Series Streaming Platform
│   ├── img1.png
│   ├── img2.png
│   ├── img3.png
│   ├── img4.png
│   └── img5.png
│
├── project2/          ← E-Commerce Web Application
│   ├── img1.png
│   └── ...
│
├── project3/          ← UI/UX Design – Mobile App
│   ├── img1.png
│   └── ...
│
└── project4/          ← Health Care Application
    ├── img1.png
    └── ...
```

## Supported formats
PNG, JPG, JPEG, WebP, GIF — any web image format works.

## Max per project
Up to **5 images** per project (img1 through img5).
